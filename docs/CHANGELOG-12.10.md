# 12.10 · Las propuestas de Tinta usan también la biblioteca original

- El motor de composición describe ahora **37 bloques** (antes 12): 25 de la biblioteca original (encabezados, tarjetas, botones y barras inferiores) además de los de Tinta. No se usan las demostraciones de estados como `lib-bot-1`.
- Nuevas reglas de diseño: **no mezclar estilos visuales** (Tinta y biblioteca se ven como dos apps distintas) y **no mezclar acentos cálidos y fríos**. Azul y violeta juntos forman una gama fría y no avisan. Un tema de un solo color no avisa; sí lo hace el mismo color repetido en tres bloques si uno es muy pesado.
- Cada idea ofrece hasta una propuesta de **otro estilo visual** cuando hay piezas que encajan bien con el sector (por ejemplo, la cafetería ofrece una con cabecera de ubicación, plato y botón naranja).
- Cada propuesta se arma dentro de un solo estilo; los candidatos mezclados se descartan de entrada.
- Pruebas: reglas de color y de estilo, variantes de otro estilo y tiempo de composición.
